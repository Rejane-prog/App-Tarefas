# Minha Lista de Tarefas

Aplicação web simples para cadastrar, visualizar e remover tarefas pessoais.

## Objetivo

Facilitar a organização de atividades por meio de uma interface simples e responsiva, aplicando na prática conceitos de Gerência de Configuração e controle de versões com Git e GitHub.

## Funcionalidades

- Cadastro de tarefas;
- Listagem de tarefas;
- Remoção de tarefas;
- Contagem automática de tarefas;
- Armazenamento no navegador com Local Storage;
- Interface responsiva.

## Tecnologias

- HTML5;
- CSS3;
- JavaScript;
- Git e GitHub.

## Estrutura

```text
app-tarefas/
├── index.html
├── style.css
├── script.js
├── README.md
├── .gitignore
```

## Como executar

1. Baixe ou clone o projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Digite uma tarefa e selecione **Adicionar**.

Não é necessário instalar dependências.
